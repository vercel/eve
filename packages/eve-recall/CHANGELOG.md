# @eve/recall

## 0.1.0-rc.0

Released 2026-11-13 · [View commits](https://github.com/vercel/eve/commits/%40eve%2Frecall%400.1.0-rc.0)

### Features

- Add the experimental `@eve/recall` package, which runs an agent in Zoom, Google Meet, and Microsoft Teams meetings through Recall.ai bots.
  The bot hears speech and chat, answers in the meeting chat, and decides which lines start a turn with an optional `shouldRespond` hook. Install it with `eve add channel/recall`. ([#4919](https://github.com/vercel/eve/pull/4919))

### Dependencies

- Updated eve to 1.0.0-rc.15.
