# eve

eve is a filesystem-first framework for durable backend AI agents. An agent is an authored directory on disk: instructions, skills, tools, connections, channels, subagents, schedules, and other framework slots are discovered from files, then compiled and run by eve.

## Source of truth

The complete documentation for the installed eve version is mounted read-only at:

```text
/eve-docs/
```

Do not rely on memory, web results, or examples from another eve version. Start with `/eve-docs/README.md`, then read the guides relevant to the framework slots being changed before writing Eve code. Read independent documentation and authored source files concurrently when possible.
