# json-render cards in Slack

An eve agent that answers in Slack with native Block Kit cards generated by [json-render](https://json-render.dev). The model writes a card spec as the input to a `card` tool, and a Slack renderer posts the card while the model is still writing it. The renderer edits the card as elements arrive and replaces it with the validated card once the spec is complete.

This is the eve version of [Chat SDK agents streaming generative UI with json-render](https://vercel.com/changelog/json-render-and-chat-sdk-agents).

## How it works

| File                               | Role                                                                                                                                                                                                                                                                                                  |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent/lib/card-spec.ts`           | The tool's input schema, with one typed variant per json-render component so the model sees each component's props. Also Slack's per-message limits.                                                                                                                                                  |
| `agent/tools/card.ts`              | Validates the spec with `toCard`. An invalid spec fails the call with one line per issue, so the model can fix it and call again.                                                                                                                                                                     |
| `agent/lib/slack-card-renderer.ts` | A [Slack renderer](https://eve.dev/docs/channels/slack/reference#customize-rendering). It parses the streaming tool input (`call.input`), posts and edits a partial card, posts the validated card on `call.requested`, and deletes the partial card if the call fails or the model stops writing it. |
| `agent/channels/slack.ts`          | Mounts the Slack channel with the renderer.                                                                                                                                                                                                                                                           |
| `agent/tools/get_deploy_stats.ts`  | Deterministic sample data worth putting in a card.                                                                                                                                                                                                                                                    |

The card is a tool call, so the spec stays in the session. Only the Slack channel renders it. Other channels, such as the eve TUI, show an ordinary tool call.

## Run it in Slack

Copy this directory out of the repository and replace `"eve": "workspace:*"` with a published version that includes Slack renderer support for `call.input`. Then set up the channel and deploy:

```bash
eve add channel/slack
eve deploy
```

If setup rewrites `agent/channels/slack.ts`, keep `renderers: [slackCardRenderer()]`. Then mention the bot: "How did deploys go last week?"
