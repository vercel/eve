# json-render cards in Slack

An eve agent that answers in Slack with native Block Kit cards generated by [json-render](https://json-render.dev). It's the eve version of [Chat SDK agents streaming generative UI with json-render](https://vercel.com/changelog/json-render-and-chat-sdk-agents).

The agent mounts the `@eve/json-render` extension, and that's all the card support it needs:

```ts title="agent/extensions/cards.ts"
export { default } from "@eve/json-render";
```

The extension contributes three things:

| File                          | What it does                                                                                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `extension/tools/card.ts`     | A `card` tool whose `replyPart` adds the model's json-render spec to the reply. An invalid spec fails the call with one line per issue, so the model fixes it and calls again. |
| `extension/renderers/card.ts` | A content renderer that turns the spec into a card. Slack previews it while the model writes the spec and replaces it with the finished card.                                  |
| `extension/instructions.md`   | When to use a card, and not to repeat it in prose.                                                                                                                             |

Channels without card support, such as SMS, post the card's fallback text. `agent/tools/get_deploy_stats.ts` supplies deterministic sample data worth putting in a card.

## Try it without Slack

`scripts/simulate-slack.mjs` runs the built agent against a local stand-in for Slack's Web API, sends one signed `app_mention`, and prints every post, edit, and delete, then the final blocks:

```bash
pnpm build
pnpm simulate "How did our deploys go last week?"
```

The model call needs AI Gateway credentials, such as `AI_GATEWAY_API_KEY` or a pulled `VERCEL_OIDC_TOKEN`.

## Run it in Slack

This example builds against the workspace `eve` and `@eve/json-render`. From the repository, set up the channel and deploy:

```bash
eve add channel/slack
eve deploy
```

Then mention the bot: "How did deploys go last week?"
