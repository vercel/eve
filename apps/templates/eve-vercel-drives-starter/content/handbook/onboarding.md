# Onboarding

## First day

- Get access to GitHub, Vercel, and Slack.
- Join the `#team` and `#deploys` Slack channels.
- Clone the main repository and run it locally.

## First week

- Pair with a teammate on a small bug fix.
- Ship one change to production.
- Read the architecture overview and ask questions in `#team`.

## Who to ask

- Access and accounts: your manager.
- Codebase questions: your onboarding buddy.
