# Threads post specs

Concrete limits and norms for a single Threads post. Specs change; confirm against Meta/Instagram help docs before relying on an edge case.

## Text

- **Character limit:** 500 characters per post.
- One idea per post. Use line breaks and short paragraphs: the feed is skimmable, not dense.
- Light emoji is fine when it carries tone; no walls of emoji.

## Topic tags

- One topic tag per post, maximum: a hard platform limit.
- Add via the `#` symbol or the tag button; you can pick an existing tag to join its conversation.
- Tags can be a multi-word phrase (spaces allowed), not just a single word.
- Tags are for discovery; posts also surface in search without a tag.

## Media

- Supports text, images, video, GIFs, and polls.
- Short-form video (under ~60s) and plain text are the formats users engage with most.
- Native, in-platform media is preferred over cross-posted or link-only content.

## Feeds

- **For You:** algorithm-ranked; rewards timely, lively conversation.
- **Following:** strictly reverse-chronological, no ranking.
