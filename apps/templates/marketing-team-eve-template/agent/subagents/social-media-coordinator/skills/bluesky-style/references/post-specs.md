# Bluesky post specs

Quick-lookup specs for drafting. Numbers reflect the standard Bluesky client at time of writing; some clients vary, so treat exact alt-text figures as approximate.

## Text

- **Post length:** 300 characters, measured in graphemes (visible characters, so an emoji counts as one). Same cap for original posts, replies, and quote posts.
- No premium tier with a higher limit: everyone gets 300.
- Links, mentions, and hashtags are rich text ("facets"): the clickable metadata is stored separately and only the visible text counts toward the 300.

## Images

- Up to 4 images per post.
- Alt text is expected on every image and does not count against the 300-character post limit. Keep it a plain, descriptive sentence or two.

## Hashtags

- Clickable and sortable (Top / Latest). Keep to ~1–2 topical tags; keyword-rich post text matters more for discovery than tag volume.

## Discovery features

- Custom feeds: user-built topic channels, some keyed to specific hashtags/keywords. Posting with the right words is how you appear in them.
- Starter packs: curated account lists newcomers follow in one click.
