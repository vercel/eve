Built-in channels show sign-ins the same way: the link or code only where the person signing in alone reads it, a link-free status in a group, and the status edited (or the ending posted) when the sign-in ends. Teams group chats and channels no longer show the sign-in link in the thread; they ask the person to continue in a direct message. Discord now shows sign-ins (the link in a DM, a status in a server channel), and GitHub posts a status saying who must sign in. Endings read the same everywhere, such as "GitHub connected." or "GitHub sign-in timed out." Teams channel state keeps `pendingAuthActivityIds`, by connection, instead of `pendingAuthActivityId`.
