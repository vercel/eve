"eve": minor

`eve add channel/slack` now reads the project's Slack state first and runs only the missing steps, so re-running it resumes an interrupted setup, including opening a fresh install page for a Slack app that was never installed in a workspace. A failed `vercel connect create` now shows Vercel's own error instead of a false "abandoned connector" cleanup failure, and a new Slack app gets a free name such as `my-agent-2` when another project already uses `slack/my-agent`, with a message naming that project. Setup checks only the connectors attached to the linked project and the UIDs it would reuse, so it stays fast on teams with hundreds of Slack connectors. It reuses a Slack connector only when no other project uses it, never attaches a second agent to one Slack app, and fixes the trigger destination without running `vercel connect detach`. `provisionSlackbot` from `eve/setup` now passes richer connector candidates to `selectConnector`, adds `already-configured`, `trigger-limit-reached`, and `connector-in-use` results, and no longer returns `detach-failed`.
