One approved session-limit prompt now starts a new usage window in every session of the delegation tree. Usage reports name the window each part was spent in, so a child's spend from before the approval no longer counts in its parent's new window, even when the report and the renewal cross in transit, and one Continue no longer leads to a second prompt from the parent or a sibling. Only the Continue option renews; Stop, other options and text-only answers do not.
