"eve": minor
---

eve now compiles one canonical source graph: framework defaults (the default `agent.ts` config, the default sandbox, the built-in tools, `connection_search`, and the `eve` and `home` channels) compose with extension packages, extension overrides, and application sources before normalization, and the compiled manifest carries required module bindings, a persisted composition report, and the channel route plan that Nitro mounts verbatim. Three surfaces break: `GET /eve/v1/info` is now version 3 (entries carry `source: { logicalPath, sourceId, owner }` provenance, channels expose the exact mounted route plan, prepared framework capabilities surface under `kernel.prepared`, and the `available`/`authored`/`framework` groupings and status taxonomy are gone, with matching client type changes and no v2 fallback); the public health and info routes now live inside the replaceable framework `eve` channel, so replacing or disabling `agent/channels/eve.ts` replaces or removes them; and the `eve/tools/defaults` barrel is replaced by per-tool subpath exports (`eve/tools/bash`, `eve/tools/read_file`, `eve/tools/write_file`, `eve/tools/todo`, `eve/tools/web_fetch`, `eve/tools/load_skill`, `eve/tools/glob`, `eve/tools/grep`), each default-exporting one ordinary tool definition — replace `import { bash } from "eve/tools/defaults"` with `import bash from "eve/tools/bash"`. `webSearch()` also accepts zero arguments now, selecting the model provider's managed web search.
