Agent calls now wait for their answer. A call to the built-in `agent` tool, a declared or dynamic subagent, or a remote agent returns the agent's answer as its tool result, instead of a `{ status: "working", taskId, agentId }` receipt followed by a notification turn; a call runs in the background only when the model of an interactive root session passes `background: true` or a steering message detaches it. The model reads each task result, waited or background, truncated to 50 KB and 2,000 lines, with any line longer than 2,000 characters cut, and receives results in `<task_result>` messages instead of prose notifications and the `[Task state]` note. `taskDeliveryPolicy` and the `TaskDeliveryPolicy` type are removed from channel and client sends and from the Chat SDK and Slack send options, along with cohorts, and a turn a schedule starts waits for its agent calls, so it posts one final reply. `execution: "background"` on `defineWorkflowTool` is replaced by `detach: true`, `eve/tools` no longer exports `TaskReceipt`, and the unused `experimental.tasks` agent option is removed. Upgrade remote agents and the agents that call them together.
