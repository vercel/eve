Add `experimental.codeMode` to the agent config and replace the experimental `Workflow` model tool with one synchronous `code_mode` orchestration option. Setting it to `true` keeps ordinary tools directly callable and also exposes typed inline tools to generated TypeScript through a capped progressive catalog with in-program search. The same structural admission rule applies to request-visible dynamic tools. With `experimental.tasks: true`, code-mode programs may stage up to eight subagent background tasks and receive working receipts, but cannot wait for child results. Eve dispatches those launches only after the program succeeds. The first-party `@ai-sdk/code-mode` package runs programs through its Run-backed isolated QuickJS runtime and returns the JSON result as an ordinary tool result. Approval-gated tools, foreground subagent calls, arbitrary background tools, provider-managed tools, and control-plane tools remain direct only. `experimental_workflow()` and the separate `Workflow` tool are removed.
