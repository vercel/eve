Replace the experimental `Workflow` tool and the `eve/tools/workflow` helper with `experimental.codeMode: true`. The framework `code_mode` tool runs a model-written JavaScript program as a durable workflow: built-in tools, authored tools, and subagents stay directly callable and can also be called from the program, while eligible dynamic tools (including discovered connection tools) are called through the program with on-demand discovery via `tools.search_tools` and `tools.describe_tools`. Each nested call runs as its own step that resumes after authorization, context updates flow back to the parent session (`CODE_MODE_STATE_CONFLICT` on concurrent writes to one field), and each program may invoke at most 100 subagents. Approval-gated tools, authored workflow tools, background tools, and framework controls stay direct only; program errors return to the model without retrying the unchanged source. Programs can call `ask_question` and await the person's answer before continuing.
