To start from your own use case, use the [eve template gallery](https://vercel.com/templates/eve) or ask your coding agent to build your use case. For example:

- “Build an eve Slack agent that answers questions from our team’s documentation.”
- “Build an eve incident-response agent that investigates alerts using our observability tools.”
- “Build an eve GitHub maintainer that triages issues and summarizes pull requests.”

For a step-by-step walkthrough, continue with this tutorial. Over eight steps you build a data analytics assistant. It answers natural-language questions, queries sample data, and runs analysis in a sandbox. It also remembers your team's metric definitions and asks before exceeding your query budget.

Step 1 gets it talking. Step 3 creates a small local dataset that you use throughout, so you need no warehouse or Vercel Connect account. [Connect a warehouse](./connect-a-warehouse) is an optional follow-up once your agent works.

## Prerequisites

- Node 24 or newer and npm.
- A working model credential, configured through [Getting Started](../getting-started).

Without a credential, "Run the agent" below fails when eve tries to reach the model. The dev TUI's `/model` flow walks you through pasting a key or linking a project.

## Scaffold the agent

```bash
npx eve@latest init analytics-assistant
cd analytics-assistant
```

`init` creates the `analytics-assistant/` directory with the starter agent and
built-in HTTP API channel (`agent/channels/eve.ts`). It also installs
dependencies, initializes Git, and offers to start the development server. If
you started the server, stop it before you continue with the edits below. `init`
does not create a Vercel project or deploy.

## Keep your configured model

`agent/agent.ts` holds the model and config. Use the same model and credentials
that worked in Getting Started; the tutorial works with any provider. To configure
this new project, use `/model` in the dev TUI before sending your first question.

## Give it an analyst persona

`agent/instructions.md` is the always-on system prompt. Replace the starter text with a standing identity for a data analyst:

```md
You are a senior data analyst. You answer questions about the team's data.

- Prefer exact numbers to hand-waving. If you can compute it, compute it.
- State the assumptions behind any number you report (date range, filters, grain).
- Use the tools available to you rather than guessing. If you cannot answer from
  the data, say so plainly.
```

Instructions are identity and standing rules. On-demand procedures belong in skills (Step 6), and actions belong in tools (Step 3). See [Instructions](../instructions).

## Run the agent

```bash
npm run dev
```

The `dev` script runs `eve dev` from the project's `node_modules`. The agent starts locally and the dev TUI opens. Ask it something it can answer from general knowledge first:

```text
What's a good way to measure week-over-week retention?
```

You get a reply that follows the analyst persona. It can't see your data yet (that comes in Step 3). First, look at what happened when you sent the question.
