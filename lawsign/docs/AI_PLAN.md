# 로싸인(LawSign) AI 연동 계획 — RAG + Qwen Max

목표: 문서함 데이터를 근거로 답하는 **RAG(검색 증강 생성) 법무 어시스턴트**를
로싸인에 탑재한다. 생성 모델은 **Qwen Max**(OpenRouter 경유, 유료)를 사용한다.

## 0. 보안 원칙 (모든 페이즈에 우선)

1. **API 키는 코드·저장소·빌드 산출물에 절대 포함하지 않는다.** 본 저장소는 공개
   저장소이므로 커밋 즉시 유출로 간주한다.
2. 프로토타입 단계: 키는 사용자가 AI 어시스턴트 화면에서 직접 입력하며 **해당
   브라우저의 localStorage에만** 저장된다 (마스킹 표시 · 원클릭 해제).
3. 실서버 단계(P4): 키는 서버 환경변수로 이동하고 브라우저는 자사 프록시
   (`POST /ai/chat`)만 호출한다.
4. **채팅·메신저 등으로 이미 전달(노출)된 키는 연동 완료 후 OpenRouter
   대시보드에서 반드시 재발급(rotate)한다.**
5. 프롬프트에는 문서 메타데이터(제목·상태·서명자명)만 포함하고, 원본 파일
   내용·연락처 상세는 사용자가 명시적으로 요청한 범위에서만 주입한다.

## 1. 아키텍처

```
[질문] ─▶ RAG 검색기 ─▶ 근거 문서 top-5 ─▶ 프롬프트 조립 ─▶ Qwen Max ─▶ [답변 + 근거 칩]
            │                                    │ (OpenRouter chat/completions)
            └ 프로토타입: 키워드 스코어링          └ 키 미설정/차단 시: 데모 응답 폴백
              실서버:    임베딩 인덱스(pgvector)
```

- 게이트웨이: `https://openrouter.ai/api/v1/chat/completions`, model `qwen/qwen-max`
- 답변은 항상 **근거 문서 칩**과 함께 표시 — 칩 클릭 시 해당 문서의 이력 모달로
  이동해 사람이 검증할 수 있게 한다 (환각 방지의 UX 장치).
- 시스템 프롬프트에 "근거 문서에 있는 사실만 사용, 없으면 모른다고 답하라"를 고정.

## 2. 페이즈별 실행

| 페이즈 | 내용 | 상태 |
|---|---|---|
| **P1 게이트웨이 어댑터** | `js/ai.js` — `LS.ai.chat()` OpenRouter 호출 래퍼, 키 저장(localStorage)·마스킹·해제, 실패 시 데모 응답 자동 폴백 | ✅ 완료 |
| **P2 RAG-라이트 검색기** | `LS.ai.retrieve()` — 질문 토큰 × 문서 메타(제목·라벨·서명자·상태) 겹침 스코어링 top-5, 의도 가중치(독촉→대기 문서, 완료→체결 문서) | ✅ 완료 |
| **P3 UI 탑재** | LNB·하단 탭 "AI 비서" / 어시스턴트 채팅 화면(제안 칩·근거 문서 칩·타이핑 인디케이터) / 컴포즈 모달 "✦ AI 초안" 버튼(채널별 발신문 생성) | ✅ 완료 |
| **P4 백엔드 이행** | `POST /ai/chat` 서버 프록시(키 서버 보관), 문서 임베딩 파이프라인(업로드 시 인덱싱, pgvector), 사용량 한도·과금 집계, PII 마스킹, AI 감사 로그(`AuditEvent type: AI_QUERY`) | ⬜ 서버 구축 시 |
| **P5 고도화** | 계약서 조항 위험 분석(업로드 PDF 텍스트 추출 후 RAG), 대량전송 수신자별 맞춤 문안, 스트리밍 응답(SSE) | ⬜ 옵션 |

## 3. 프로토타입 동작 규약

- 키 미설정: **데모 응답 모드** — RAG 검색은 실제로 수행하고, 생성부만 결정론적
  템플릿(현황 요약·독촉문·문서 목록)으로 대체. 배지로 데모임을 명시.
- 키 설정: 실제 Qwen Max 호출 (`max_tokens 700`, 최근 3턴 히스토리 동반).
  네트워크 실패 시 오류를 표기하고 데모 응답으로 폴백 — 화면이 죽지 않는다.
- 트래픽 계약: 요청당 1회 호출(스트리밍 없음), 근거 문서는 최대 5건만 주입해
  토큰 비용 상한을 고정한다.

## 4. 실서버 API 계약 (P4 선행 설계)

| Method | Path | 설명 |
|---|---|---|
| POST | `/ai/chat` | `{messages[], scope?}` → 서버가 RAG 검색 + OpenRouter 호출 후 `{text, sources[]}` 반환. 202 아님(동기), 30s 타임아웃 |
| POST | `/ai/draft` | `{documentId, channel}` → 발신문 초안 `{text}` |
| GET | `/ai/usage` | 워크스페이스 월 사용량·한도 (과금 가드) |

- 서버는 요청자 JWT의 워크스페이스 스코프로 문서 접근을 제한하고, 모든 호출을
  감사 로그에 남긴다. Rate limit: 사용자당 분당 10회.
