## 2. 메모리 누수 점검

- 6개 화면을 25회 순환 후 강제 GC → JS 힙 **2.9MB → 2.9MB (증가 0.00MB)** — 누수 없음.
- 정적 점검: 전역 리스너(hashchange·ESC)는 1회 등록, 발송 프로그레스 `setInterval`은 성공/실패
  양쪽에서 해제, 포인터 드래그 리스너는 pointerup에서 제거, 모달/토스트 DOM은 제거 시 참조 해제 확인.
- 개선 여지(비차단): 메일함 본문 갱신 시 폴더 레일 건수도 함께 재질의(중복 API 1회) — 실서버
  전환 시 요약 카운트 API로 통합 권장.

## 3. 무결성 교차 검증

- GitHub raw가 서빙하는 4개 자산(css/app.css, js/api.js, js/app.js, js/request.js)과 로컬 원본의
  **바이트 동일성**을 curl-diff로 확인 (IDENTICAL ×4).
- CI 빌드의 단일 실행본 크기(138,920B)가 로컬 빌드와 정확히 일치.
