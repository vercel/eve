## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 목표 | 단방향·평면적 전자서명 UI를 탈피하여, 대량의 법률 문서·계약서를 직관적이고 빠르게 처리하는 **반응형·데이터 시각화 중심** 프론트엔드 구축 |
| 타겟 사용자 | 다수의 수임 사건과 계약을 동시에 처리하는 법무법인, 기업 법무팀, 일반 기업 실무자 |
| 핵심 방향 | ① 데스크탑 중심 화면의 모바일·태블릿 네이티브 수준 대응, ② 문서 파이프라인 시각화(칸반), ③ 해시 기반 위변조 방지·감사추적으로 법적 증거능력 확보 |
| 기대 효과 | 3단계 페이지 이동형 폼 → 1-Depth SPA 전환으로 **작업 소요 시간 40% 단축**, 우측 체크리스트 패널로 **입력 누락(휴먼 에러) 시스템적 차단** |

### 1.1 권장 기술 스택 (프로덕션)

| 계층 | 선정 | 사유 |
|---|---|---|
| 프레임워크 | React 19 + TypeScript | 컴포넌트 재사용·타입 안정성 |
| 상태 관리 | Zustand (문서 데이터 정규화) | 필드 이동 시 캔버스 계층만 리렌더링 |
| 스타일링 | Tailwind CSS + 디자인 토큰 | 라이트·다크 자동 대응, 반응형 분기 |
| 차트 | Recharts | 반응형 SVG 꺾은선/영역 차트 |

> 납품 프로토타입은 검수 편의를 위해 의존성 0의 순수 HTML/CSS/JS로 동일한 IA·인터랙션을 구현했다. 프로덕션 전환 시 화면 단위로 위 스택에 이식한다.

## 2. 화면별 AS-IS 분석 및 TO-BE 설계

### 2.1 홈 대시보드

**AS-IS**: '내 서명 필요 / 상대 서명 필요 / 서명 완료' 건수를 텍스트로만 제공. 중앙의 '첫 이용자 가이드' 영역이 실무 가치 없이 공간 점유.

**TO-BE** (프로토타입 `#/dashboard` 구현 완료):

1. **서명 파이프라인 현황** — 상태별 집계 카드 4종(클릭 시 해당 상태로 필터된 칸반으로 이동) + 최근 30일 완료 추이 꺾은선 차트.
2. **마감 임박·요주의 위젯** — '상대 서명 대기' 3일 경과 문서를 최상단 노출, 카드 내 **원클릭 독촉 알림(카카오톡·이메일)** 버튼. 경과일 뱃지 자동 렌더링.
3. **퀵 템플릿** — 이용 가이드 대체. 합의서·처벌불원서·위임장 등 자주 쓰는 양식을 원클릭으로 서명 요청 플로우에 주입(필드 좌표 사전 세팅 포함).

### 2.2 문서함 — 칸반 보드 뷰 도입

**AS-IS**: 수많은 상태가 좌측 LNB에 파편화, 우측은 단순 테이블. 전체 계약 흐름 파악 불가.

**TO-BE** (프로토타입 `#/documents` 구현 완료):

- **보기 모드 토글**: 기존 사용자를 위한 리스트 뷰 ⇄ 칸반 뷰 전환.
- **칸반 컬럼 4단 파이프라인**: `요청 전(작성·예약)` → `내 서명 필요` → `상대 서명 대기` → `서명 완료됨`. 거절·취소는 숨김 컬럼(토글 노출)으로 복잡도 억제.
- **칸반 카드**: 라벨 뱃지 / 더보기(⋮) 메뉴 / 제목 2줄 말줄임 / 참여자 / 마지막 활동 시각. `긴급` 문서는 경고 뱃지, 3일 경과 대기 건은 **붉은 보더 + ⏳ 리마인드 필요 뱃지 자동화**.
- **Optimistic UI 드래그 앤 드롭**: 카드 이동 시 UI 즉시 반영 → 서버 `PATCH` 후행 → 실패 시 원위치 롤백. `요청 전 → 상대 서명 대기` 이동 시 발송 확인 모달 연결.
- **필터 상태 URL 보존**: `#/documents?view=kanban&status=…&q=…&label=…` — 북마크·뒤로 가기·공유 시 필터 재현. 검색은 500ms 디바운스 후 1회 질의.
- **가상화 렌더링**: 완료 컬럼(수백~수천 건)은 뷰포트 내 카드만 렌더링(react-window / Intersection Observer).

### 2.3 서명 요청 플로우 — SPA Seamless Stepper

**AS-IS**: 서명자(1단계) → 필드 입력(2단계) → 기타 설정(3단계)의 선형 페이지 이동 구조. 중간 수정 시 이탈 피로.

**TO-BE** (프로토타입 `#/request` 구현 완료):

- 화면 전환 없는 **단일 뷰 스테퍼** — 상단 스텝 필을 클릭해 자유롭게 단계 간 이동, 단계별 입력은 draft 상태로 보존(임시저장 표시).
- **1단계 스마트 연락처**: 이메일·전화번호 일부 입력 시 300ms 디바운스로 서버 자동완성 질의 + 프론트 형식 유효성 즉시 표시. '순서대로 한 명씩 서명' 토글 시 우측 패널에 서명 순서 플로우 미리보기.
- **3단계 체크리스트 패널**: 서명자 수·필드 수·완료 문서 잠금·외부 참조자 설정을 우측 고정 패널에서 검사해 발송 전 누락 차단.
- **발송 UX**: 발송 즉시 문서함으로 리다이렉트, 우하단 플로팅 프로그레스로 백그라운드 발송 표시(멀티태스킹 보장). 대량 전송은 Service Worker 큐 위임.

### 2.4 문서 편집기 (서명 필드 배치)

**TO-BE** (프로토타입 2단계 편집기 구현 완료):

- **Touch & Floating 생성**: 도구 탭 시 화면 중앙에 필드 즉시 스폰 → 미세 위치만 조정. 긴 드래그로 인한 모바일 터치 유실 원천 차단.
- **자석 스냅(Magnetic Snap)**: 드래그 중 필드 하단이 문서 텍스트 베이스라인 근접(±1.6%) 시 자동 흡착 + 점선 가이드 표시. 실서비스는 PDF.js 텍스트 레이어 좌표에서 베이스라인 추출.
- **상대 좌표계(%) 저장**: 필드 위치를 px가 아닌 원본 대비 비율(x: 35.2%, y: 81.5%)로 저장 — 리사이즈·회전·해상도 변화에도 위치 불변.
- **Pointer Events 단일 처리**: 마우스·터치·스타일러스 공통 대응. 제스처 분리(1지 = 필드 이동, 2지 = 캔버스 핀치/팬).
- **다중 페이지 일괄 적용**: 선택 필드를 '모든 페이지 동일 위치에 복사' — 수십 장 문서의 매 페이지 하단 서명 시나리오 대응.
- **서명자별 색상 코드**: 필드 보더 색으로 담당 서명자를 즉시 식별.

### 2.5 위변조 검증 포털 (LawSign Validator)

**TO-BE** (프로토타입 `#/validator` 구현 완료):

- 비로그인 외부인(판사·수사기관·거래처)용 독립 검증 페이지.
- **Zero-Knowledge 클라이언트 해싱**: 파일 드롭 시 브라우저 `crypto.subtle.digest('SHA-256')`로 즉석 해시 계산. **원본 파일은 절대 서버로 전송하지 않고 해시 문자열만 대조** — 검증 과정의 문서 유출 위험 0.
- 일치 시 초록 카드(제목·발행처·완료일시·TXID·💎 블록체인 증명 뱃지), 불일치 시 붉은 경고 카드.
- 인쇄물 검증: 완료 PDF 여백에 검증 포털 딥링크 QR 워터마크 삽입 → 스캔 시 원본 뷰어와 육안 교차 대조.

### 2.6 감사추적 인증서 (Audit Trail Certificate)

**TO-BE** (프로토타입 `#/certificate?id=…` 구현 완료): 완료 PDF 마지막 페이지에 자동 병합되는 1페이지 증명서.

- §1 문서 기본 정보(ID·제목·발행처·기한·잠금 상태)
- §2 무결성 정보 — SHA-256 해시·블록체인 TXID를 **모노스페이스 폰트 + 음영 칩**으로 강조
- §3 서명 진행 타임라인 — 발행/열람/서명/잠금을 상태 이모지·IP·User-Agent와 함께 초 단위 기록 (Scannability 극대화)
- 우상단 검증용 QR(Z-패턴 시선 유도), 인쇄 CSS(`@media print`) 지원

## 3. 반응형·디바이스별 UX 명세

### 3.1 모바일 (≤768px) — 프로토타입 반영 완료

| 항목 | 설계 |
|---|---|
| 내비게이션 | LNB → **하단 고정 Bottom Tab Bar** (홈·문서함·서명요청·검증), `safe-area-inset` 대응 |
| 레이아웃 | 2단 그리드 → 단일 열 스택, 통계 카드 2×2, CTA 버튼 Full-width |
| 칸반 | 세로 컬럼 → **가로 스와이프 캐러셀**(컬럼당 78vw) |
| 편집기 | 도구 팔레트 → **하단 바텀 시트**(가로 스크롤), 썸네일 레일 숨김 → 헤더 페이지 인디케이터 탭 시 바텀 모달 |
| 텍스트 | 긴 법률 문서 제목 `line-clamp` 1~2줄 말줄임으로 레이아웃 방어 |

### 3.2 모바일 정밀 배치 (Fat-finger 극복)

- 제스처 분리: 1-finger 필드 이동 / 2-finger 캔버스 줌·팬 (`touch-action: none` + Pointer Events)
- **돋보기(Loupe) UI**: 드래그 시작 시 손가락 상단에 1.5~2배 확대 원형 렌즈 렌더링 (프로덕션 항목)
- **넛지(Nudge) 컨트롤**: 선택 필드 툴팁에 상/하/좌/우 1px 미세 조정 버튼 (프로덕션 항목)

### 3.3 태블릿 (가로 모드)

- 좌측 고정 패널 → **플로팅 툴 팔레트**(드래그 재배치, 좌/우손잡이 대응)
- **Stylus-First**: `event.pointerType === 'pen'` 감지 시 즉시 서명 모드(Direct Draw) + 팜 리젝션(펜 입력 중 터치 무시)
- 이전/다음 버튼을 좌·우 하단 코너로 분리 — 양손 파지 시 엄지 영역(Thumb-zone) 배치
- 우측 썸네일 → Edge Swipe 오버레이 서랍

## 4. 성능 최적화 아키텍처

### 4.1 PDF 렌더링

1. **DPR 동적 스케일링**: `window.devicePixelRatio` 기반 캔버스 스케일 조정으로 레티나 텍스트 깨짐 방지.
2. **Web Worker 파싱**: PDF.js 파싱·텍스트 좌표 추출을 백그라운드 스레드로 위임 — 로딩 중에도 UI 무정지.
3. **뷰포트 가상화**: Intersection Observer로 화면 내 1~2페이지만 캔버스 렌더링(Lazy Loading).
4. **리사이즈 디바운싱**: `resize` 종료 후 300ms 뒤 1회만 재계산. 필드는 상대 좌표(%)라 재계산 비용 최소.

### 4.2 API 트래픽 방어 (프론트엔드 1차 방어선)

| 시나리오 | 정책 |
|---|---|
| 필드 드래그 자동 저장 | UI는 60fps 즉시 반영(Optimistic), `PUT /documents/{id}` 는 조작 종료 후 **1,000ms 디바운스 1회** Bulk Update |
| 문서 검색 | 타이핑 **500ms 디바운스** 후 완성 질의 1회 (프로토타입 구현) |
| 연락처 자동완성 | **300ms 디바운스** + 최소 2자 (프로토타입 구현) |
| 창 리사이즈 | 300ms 디바운스 후 캔버스 1회 재렌더 |

### 4.3 저사양 기기 이미지·메모리 전략

- **LRU 캐시 축출**: 뷰포트 이탈 썸네일을 DOM + 메모리 캐시에서 우선 해제(OOM 크래시 방지), 재진입 시 Cache API 복원.
- **PWA 정적 캐싱**: Service Worker로 아이콘·템플릿 썸네일을 Cache Storage 영구 캐싱 — 재방문 0초 로딩.
- **CDN 동적 리사이징**: `?w=300&format=webp` 요청으로 기기 폭 맞춤 WebP/AVIF 전달, `<picture>`+`srcset` 선택 로드.
- **Skeleton + Blur-up**: 원본 로딩 전 1KB 미만 Base64 썸네일 블러 표시 → 크로스페이드 전환, CLS 제거.

## 5. 위변조 방지·무결성 아키텍처 (백엔드 연계)

```
 서명 완료(잠금) ──▶ 백엔드: 최종 PDF 버퍼 SHA-256 생성
                       │
                       ├─▶ verification_records DB 박제 (해시·메타·감사로그)
                       ├─▶ (선택) 프라이빗 블록체인 트랜잭션 기록 → TXID
                       └─▶ 감사추적 인증서 페이지 병합 + 검증 QR 워터마크
 외부 검증인 ──▶ validate.lawsign.com : 브라우저 해싱(Zero-Knowledge) → 해시만 대조
```

- **부인 방지**: 서명자별 IP·User-Agent·타임스탬프를 audit log로 초 단위 기록.
- **스마트 컨트랙트 이중 통제(고도화)**: 서명 기한 만료 시 컨트랙트 레벨에서 서명 트랜잭션 거부 — 사후 조작 차단.
- **표시 UX**: 완료 카드에 `💎 해시 증명` 뱃지, 인증서·이력 모달에 TXID 링크(독립 블록 탐색기 연결).
- 상세 스키마·엔드포인트: [`API.md`](./API.md) §3, §6 참조.
