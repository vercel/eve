# 로싸인(LawSign) UI/UX 업그레이드 실행 계획 (Phased Plan)

> v1.0 프로토타입 검수 중 발견된 이슈(외부 뷰어에서 스타일 미적용)와
> 이용자 관점 개선 항목을 3개 페이즈로 나누어 실행한다.

## Phase 1 — 복구·안정화 (Delivery Hardening)

배경: 일부 렌더링 환경(샌드박스 뷰어, HTML 새니타이저)이 본문 `<style>` 태그를
제거하여 스크립트만 실행되고 디자인이 전부 소실되는 문제 확인.

| # | 항목 | 내용 |
|---|---|---|
| 1-1 | **CSS 이중 주입** | 단일 파일 배포본은 CSS를 JS 문자열로 내장하고 부팅 시 `document.head`에 주입 — `<style>`이 제거되는 환경에서도 스타일 보장 |
| 1-2 | **단일 파일 빌드 스크립트** | `scripts/build-standalone.mjs` — css/js를 조립해 `frontend/lawsign-standalone.html` 생성. 고객은 파일 1개만 열면 됨 |
| 1-3 | **접근성 기반** | `:focus-visible` 포커스 링, `prefers-reduced-motion` 시 전환·애니메이션 제거 |

## Phase 2 — 시각 완성도 (Visual Refinement)

이용자 관점 진단:

- 모바일에서 LNB가 숨겨지면 **로고·워크스페이스 컨텍스트가 완전히 사라짐** → 상단 앱바 필요
- 로딩 중 "불러오는 중…" 텍스트는 레이아웃 점프(CLS) 유발 → 스켈레톤 필요
- 검색 결과 0건 등 빈 상태가 무성의한 한 줄 텍스트 → 행동 유도형 Empty State 필요

| # | 항목 | 내용 |
|---|---|---|
| 2-1 | **모바일 상단 앱바** | ≤768px에서 로고·테마 전환·새 요청 버튼을 고정 상단 바로 제공 |
| 2-2 | **스켈레톤 로딩** | 화면 전환 시 카드형 스켈레톤(shimmer) — 체감 속도 개선, CLS 제거 |
| 2-3 | **Empty State** | 문서함·요주의 위젯 0건 시 일러스트 + 원클릭 CTA(새 서명 요청) |
| 2-4 | **마이크로 인터랙션** | 버튼 press 스케일, 카드 hover 정리 — reduced-motion 존중 |

## Phase 3 — 사용성 심화 (Interaction Depth)

| # | 항목 | 내용 |
|---|---|---|
| 3-1 | **차트 호버 툴팁** | 30일 추이 차트에서 마우스/터치 위치의 일자·건수 즉시 표시 |
| 3-2 | **칸반 이동 실행취소** | DnD 상태 변경 토스트에 「실행취소」 — 오조작 즉시 복구 (법무 데이터 안전망) |
| 3-3 | **ESC 모달 닫기** | 키보드 사용자 흐름 유지 |
| 3-4 | **페이지 헤더 일관화** | 전 화면 동일한 타이틀·설명·액션 배치 규칙 적용 |

## 후속 로드맵 (프로덕션 이관 시)

- 검색 결과 키워드 하이라이트, 칸반 컬럼 접기, 목록 정렬 옵션
- 스크린리더 라이브 리전(토스트 `aria-live`), 전 화면 키보드 내비게이션 감사
- 디자인 토큰의 Tailwind 테마 변환 및 Storybook 컴포넌트 카탈로그
